# focus-flow
FocusFlow 是一個情境式專注助手，使用者可以選擇目前進行的任務、精神狀態、所在環境與可用時間，系統會依照輸入條件產生不同的專注模式、專注時間、休息時間與背景聲音建議。 網頁另外加入 Focus Timer、Break Timer、Brown Noise 播放、自訂任務、Dark Mode、完成動畫，以及利用 LocalStorage 儲存每日 Session、專注分鐘與使用紀錄等功能。 開發過程中，我先利用 AI 討論並整理網站規格，再透過 Vibe Coding 建立第一版網站。實際測試後，我進一步要求 AI 增加 Brown Noise、自訂任務、完成動畫與介面改善，形成第二版作品，使實際網頁逐步接近原先規格。
